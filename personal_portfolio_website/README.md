# Personal Portfolio Website

A responsive personal portfolio built with HTML, CSS, and basic JavaScript. It includes Home, Education, Future Aspirations, and Contact sections with working in-page navigation.

## Files
- `index.html` — page structure and portfolio content
- `style.css` — layout, colours, responsive design, and mobile navigation styling
- `script.js` — mobile menu, active section navigation, current year, and contact form validation

## How to run it
1. Extract the ZIP file.
2. Open the `personal_portfolio_website` folder in Visual Studio Code.
3. Open `index.html` in a browser. For a convenient development workflow, install the **Live Server** extension in VS Code, right-click `index.html`, and choose **Open with Live Server**.

The website works as a static website; it does not need a database or a build tool.

## Personalise before presenting
Search the files for the square-bracket placeholders and replace them with your actual details:
- `Your Name`
- school, college/university, course, and year of study
- location and contact email
- education details, skills, and aspirations

For the contact form, replace `your.email@example.com` in **both** `index.html` and `script.js` with your real email address. The form validates input and prepares an email in the visitor's default email app; it does not send messages directly from the site. Direct submission requires a server or a form service.

## Presentation checklist
- Test every navigation link.
- Test the menu on a narrow/mobile screen.
- Submit the contact form with missing/invalid data to demonstrate validation.
- Check spelling and replace every placeholder with truthful personal information.
- If using an external font, internet access is needed for the Google Fonts styling; fallback fonts are included.
